# Pokémon Z Mods v1.1.6

Corrige la selección de MT que podía entregar objetos comunes aunque todavía faltaran MT. Añade una compensación opcional para las partidas afectadas y detección automática de Pokémon Z ES 2.19.

## MT y partidas antiguas

- Se elige directamente entre las MT que faltan, sin agotar intentos sobre las ya poseídas. Solo se sustituye por un objeto común cuando se ha completado el catálogo.
- Las listas de MT incompletas del guardado se reconstruyen desde los datos de la edición.
- **Desafíos → Compensar MT perdidas** permite indicar cuántas MT se perdieron y recibir esa cantidad de MT aleatorias que aún no se posean. Se permite una única compensación por guardado y hay que guardar normalmente después.
- El guardado antiguo no registra cada pérdida: la cantidad es manual y la compensación no reconstruye el resultado aleatorio exacto. Las runs que activan Random con este arreglo no ofrecen esta opción.
- Se conservan las MT y asignaciones de movimientos existentes. Las nuevas asignaciones respetan la progresividad. Si una entrega falla, se revierte completa sin consumir el uso.

Los recursos de nodos renovables mantienen su política anterior. El caso concreto de una NPC que entrega Carantoña y las piedras que entregan Antiderretir aún necesita su ubicación para identificarlo. No se cambia la indicación **R: Tipos**.

## Instalación y compatibilidad

Cierra el juego y conserva una copia de tu partida. En Android, actualiza la APK y pulsa **Instalar / actualizar mod** sobre la carpeta del juego; actualizar solo la APK no actualiza los archivos del mod. Después carga tu partida y abre el menú Desafíos para usar la compensación si procede.

En Windows, ejecuta el instalador sobre la carpeta existente. En Steam Deck/Linux, usa `install.sh` o `python3 installer/install.py <carpeta> --profile <perfil>`. Se conservan las partidas y `Data/Scripts.rxdata`.

ES 2.18 y ES 2.19 comparten el perfil `es_218`. Los instaladores Windows, Python y Android reconocen la firma de ES 2.19 aunque se renombre la carpeta. El ZIP manual español conserva el nombre `ES-2.18` y sirve para ambas ediciones.

Incluye las correcciones anteriores de Tipos random y movimientos desactivados.

## Descargas

- `Pokemon-Z-Mods-v1.1.6.zip`: paquete universal con instaladores Windows/Python.
- `Pokemon-Z-Mods-v1.1.6-Android-Installer.apk`: instalador Android experimental, firmado con la misma clave del proyecto que las APK anteriores.
- `Pokemon-Z-Mods-v1.1.6-Android-JoiPlay-ES-2.18.zip`, `…EN-2.13.zip` y `…FR-2.12-Patch1.zip`: alternativas manuales para cada perfil.
- `SHA256SUMS.txt`: sumas SHA-256 de los cuatro ZIP y la APK.

## Comprobaciones

Pruebas con el Ruby 1.8.7 y los datos reales de ES 2.18/2.19, EN 2.13 y FR 2.12 + Patch 1: MT pendientes, listas antiguas incompletas, entregas por mapa/NPC con 0/4/8 medallas, movimientos guardados y agotamiento real. La compensación comprueba cantidades, exclusión de MT poseídas y partidas nuevas, asignaciones conservadas, cancelación, confirmación, uso único tras recarga en memoria y reversión ante escrituras parciales o excepciones.

También se comprueban la instalación automática, las firmas Java, los paquetes y la APK. Estas pruebas no escriben partidas ni equivalen a una partida completa. No hay una nueva validación en un dispositivo Kirin; su compatibilidad de ejecución sigue sin confirmarse.
